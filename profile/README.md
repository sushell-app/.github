### Descripción General

**Sushell** es una organización tecnológica dedicada al desarrollo de plataformas SaaS, arquitecturas de inteligencia artificial multi-agente y soluciones de infraestructura crítica. Nuestro enfoque combina sistemas de bajo acoplamiento, alto rendimiento y control directo sobre cada capa de despliegue.

### Ecosistema de Productos

| Plataforma | Categoría | Descripción |
| :--- | :--- | :--- |
| **[Sushell One](https://app.sushell.com)** | Cloud & Dev Hub | Plataforma centralizada para la administración de infraestructura, servidores, licencias, facturación y herramientas para desarrolladores. |
| **Orbit** | Enterprise AI | Sistema B2B SaaS multi-agente para atención automatizada en tiempo real y gestión operativa asistida por inteligencia artificial. |
| **FELvus** | FinTech & POS | Punto de venta web y motor de facturación electrónica optimizado para terminales bancarios (Sunmi P2) y comercios físicos. |
| **Ordo ID** | Identity & Access | Infraestructura de autenticación única (SSO), gestión de identidad, tokens criptográficos y control de permisos OAuth. |
| **Portal HSE** | Corporate Safety | Sistema empresarial para la gestión de seguridad industrial, cumplimiento normativo y control de acceso de contratistas. |
| **[Help Center](https://help.sushell.com)** | Documentation | Centro de documentación técnica de alta velocidad con asistencia inteligente integrada. |

### Arquitectura y Tecnologías

* **Backend & Sistemas:** PHP Nativo (arquitectura modular de baja latencia), Node.js, Python.
* **Frontend & Interfaces:** JavaScript (ES6+), Tailwind CSS, Astro, HTML5, CSS3.
* **Datos & Almacenamiento:** MySQL y MariaDB bajo esquemas relacionales de alto rendimiento.
* **Inteligencia Artificial:** Orquestación de modelos fundacionales mediante Groq, Google Gemini, OpenAI y Anthropic Claude.
* **Infraestructura & Seguridad:** Entornos Linux (Ubuntu / Arch), cPanel, Vercel, control de versiones en Git y análisis estático continuo (Semgrep / Gitleaks).

### Estándares de Ingeniería

1. **Arquitectura Previa:** Todo requerimiento técnico se especifica, audita y planifica en **Linear** antes de iniciar su implementación.
2. **Seguridad por Diseño:** Aislamiento estricto de credenciales, privilegios mínimos por servicio y auditoría automatizada previa al despliegue en producción.
3. **Mantenibilidad:** Código modular, documentado y sujeto a revisión por pares mediante flujos estructurados en Git.
