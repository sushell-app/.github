### Perfil Corporativo

**Sushell** diseña, desarrolla y escala ecosistemas tecnológicos a la medida. Construimos desde plataformas SaaS e integraciones de inteligencia artificial hasta arquitecturas cloud, sistemas de gestión (ERP/CRM) y seguridad empresarial, priorizando velocidad, bajo acoplamiento y control total sobre nuestra infraestructura.

### Ecosistema Tecnológico y Proyectos

| Proyecto | Categoría | Alcance Operativo |
| :--- | :--- | :--- |
| **FELvus** | FinTech & POS | Sistema de punto de venta y gestión de inventario en vivo en la nube, con integración a certificadores autorizados por la SAT para emisión automática de DTE. |
| **Sushell APIs** | Developer Platform | Capa tecnológica central para consumir, integrar y administrar servicios técnicos, licencias y credenciales mediante API Keys. |
| **Cuenta Sushell** | Identity & Security | Sistema de identidad central y acceso unificado con gestión estricta de sesiones, protección mediante OTP/MFA y emisión segura de tokens. |
| **Portal HSE** | Enterprise Compliance | Plataforma corporativa para el control de acceso de contratistas, trazabilidad operativa y gestión de seguridad industrial. |
| **Centro de Soporte** | Documentation | Base de conocimientos y documentación técnica de alta velocidad para clientes y desarrolladores. |
| **Fedired Systems** | Cloud Infrastructure | Infraestructura de servidores compartidos, VPS y respaldo operativo de alta disponibilidad. |

### Arquitectura y Stack Técnico

* **Sistemas & Backend:** PHP Nativo (arquitectura modular de alto rendimiento), Node.js y Python.
* **Interfaces & Frontend:** JavaScript (ES6+), Tailwind CSS, Astro, HTML5 y CSS3.
* **Bases de Datos:** Motores relacionales MySQL y MariaDB optimizados para baja latencia.
* **Infraestructura & Ecosistema:** Servidores Linux, cPanel, Vercel, integración de pasarelas de pago (Recurrente / PayPal), control de versiones en Git y auditoría continua (Semgrep / Gitleaks).

2. **Seguridad por Diseño:** Aislamiento estricto de credenciales, privilegios mínimos y validación previa al despliegue en producción.
3. **Calidad y Rendimiento:** Código limpio, modular y respaldado por control de versiones en Git.
